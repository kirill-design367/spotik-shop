⚠️ ПРОВЕРКА «НАЗНАЧЕН ПОВТОР» ПЕРЕПИСАНА ПОСЛЕ ПАДЕНИЯ ВЫКЛАДКИ № 84.
Она сравнивала срок повтора с `now()` — это гонка: строка созревает
через минуту после вставки, а будильник ходит по своим шестидесяти
секундам от старта процесса, и между «срок подошёл» и «будильник
дошёл» состояние совершенно исправное, а проверка падает.

Замер по базе, восемь проб через 8 с подряд (одна минута):

    17:34:12  старая (>now): false   новая (>created_at): true
    17:34:20  старая (>now): false   новая (>created_at): true
    17:34:28  старая (>now): false   новая (>created_at): true
    17:34:36  старая (>now): false   новая (>created_at): true
    17:34:44  старая (>now): false   новая (>created_at): true
    17:34:52  старая (>now): false   новая (>created_at): true
    17:35:00  старая (>now): false   новая (>created_at): true
    17:35:08  старая (>now): false   новая (>created_at): true

То есть старая проверка ложна БОЛЬШУЮ ЧАСТЬ ВРЕМЕНИ, а два локальных
прогона до этого прошли по везению. Инвариант же настоящий и от
момента чтения не зависит: каждый путь кода назначает срок как
`now() + интервал`, то есть строго позже рождения строки.

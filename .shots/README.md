# Замеры и скриншоты

Каталог не входит в сборку. Здесь лежат результаты проверок, снятые
скриптами из `scripts/`, и кадры с боевой выдачи.

- `final/` — скриншоты собранного экспорта на 390×844, 1920×1080, 2560×1440
- `footer/` — четыре состояния хода футера плюс «уменьшить движение»,
  на 390×844 и 1920×1080 (`shoot-footer.mjs`)
- `fps.txt` — фактические интервалы кадров
- `mobile-scroll.txt` — потерянные кадры мобильного скролла по блокам
- `smooth.txt` — выбег страницы, схождение формы, ступеньки на жесте
  и дискретная инерция: разных состояний формы на кадр
- `focus.txt` — подсветка касания и кольцо фокуса
- `wordmark-continuity.txt` — плавность морфа и поведение скролла
- `navpaint.txt` — инверсия шапки по растру на всех трёх фонах
- `bundle.txt` — критический путь и асинхронные чанки
- `nav/` — рабочие кадры полосы шапки на четырёх фонах (в историю
  не попадают, снимаются `shoot-nav.mjs`)
- `verify-strokes.txt` — сверка приёма с замерами референса
- `lh-mobile.json`, `lh-desktop.json` — отчёты Lighthouse

Пересобираются командами из README.
